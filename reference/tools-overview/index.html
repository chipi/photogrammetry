    Tools overview¶

    The catalogue of every tool, library, model, format and product that bears on the photogrammetry project, kept open as a lookup while designing and prototyping. It merges the two research notes (landscape, Metashape and underwater) with a licence and platform pass done the same day. As of 2026-11-23.

    Verification. [V] = read on a primary page on 2026-11-23 (GitHub repo and LICENSE file, official docs, PyPI file list); the URL follows. [U] = memory, a search snippet or a secondary page; a lead, not a fact. A [V] carried from a research note keeps that note's reading. Where the platform column cites "wheels", it is the PyPI file list read today, not an install test.

    Licence classes. Permissive (MIT, BSD, Apache-2.0, MPL-2.0 file-level) · Copyleft (GPL, LGPL, AGPL) · Non-commercial (CC-BY-NC, research-only, NVIDIA non-commercial) · Custom (a bespoke agreement that is neither OSI-permissive nor non-commercial, read the text) · Proprietary.

    Role. Default = in the permissive default stack. Plug-in = optional, labelled, never required. Reference = compared against or read, not shipped. Not used.

    Policy. The default stack is permissive so it can be open-sourced. Non-commercial weights and AGPL/GPL tools are optional plug-ins. Engine is Python first. Machines: M4 Pro (Metal), GB10 (ARM64 + CUDA 13), X3 (ROCm/HIP or Vulkan, x86_64 Linux), iMac Pro (CPU, macOS x86_64).

    19. Licence traps¶

    1. VGGT, Pi3, DUSt3R/MASt3R, original MapAnything weights are non-commercial. Only map-anything-apache (Apache-2.0) and the form-gated VGGT-1B-Commercial are commercial-safe. Code under a permissive licence does not license its weights.
    2. SuperPoint is restrictive and so is its inference file in LightGlue (lightglue/superpoint.py). LightGlue's README states its own code and weights are Apache-2.0; the research note's claim that SuperPoint-trained LightGlue weights inherit the restriction is not what the README says. Decide with a lawyer's eye, or avoid by default: ALIKED/DISK + LightGlue.
    3. AGPL: OpenMVS, OpenSplat [U], WebODM. A hosted service must offer source. Plug-ins only, run as separate processes.
    4. GPL: PyMeshLab (GPL-3.0), TagLab, Sea-Thru-Impl, MeshLab, darktable [U]. Do not link into the engine. PyExifTool is listed "GPLv3+/BSD" on PyPI: check which applies, or call exiftool directly.
    5. LGPL: LibRaw (also CDDL option), libheif, record3d. Wheels bundle the libraries; dynamic linking and shipping notices apply. LibRaw's CDDL option is the way out of LGPL.
    6. SAM 3 is a custom licence, not Apache. Grant is broad but carries trade-control and military end-use terms and a duty to ship the agreement; checkpoints are gated. SAM 2 is Apache-2.0.
    7. Open GoPro repo has no licence statement; only the Python SDK is MIT. Treat the spec text and demos as unlicensed until clarified.
    8. COLMAP "BSD-3" excludes dependencies: a CUDA, FreeImage or similar build may carry other terms.
    9. Instant-NGP and Inria 3DGS are non-commercial [U]; RUSplatting is research-only.
    10. rembg model weights (u2net, etc.) have their own licences, unread.
    11. Proprietary SDKs (DJI MSDK, Record3D app, Polycam, Apple Object Capture) are interop targets, never dependencies.
