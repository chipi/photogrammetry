# photogrammetry

*Working name.* An open-source reconstruction engine that turns photographs into 3D models (camera poses, point clouds, meshes and gaussian splats) and says what it knows and what it does not: scale, frame, coverage and uncertainty.

The project is in its concept phase. There is no engine code yet; the concept package and a set of prototypes test the riskiest assumptions first.
